Agentic Streaming

Agentic Streaming builds agents as streaming, stateful, event-sourced systems. An agent's state is a materialized view over an ordered log of events. Processing a turn is a command; reading the view is a query; each conversation has a single writer.

Runtimes

The agentic/v1 specification is executed by a reference runtime and by bindings for Apache Flink, Apache Pekko, Clojure, and Python. A conformance harness runs the same fixtures against every binding and generates the capability matrix.

Knowledge base

The KnowledgeBase component fetches a page, extracts its text, splits the text into chunks, embeds each chunk, and stores the vectors in a vector store. Search embeds the question and returns the nearest chunks. With a chat connection configured, ask returns an answer grounded in the retrieved passages with citations.
