# Parity matrix (retired)

This page used to carry two hand-maintained tables: a three-core feature list and a per-backend
capability and limitation table. Both duplicated, and drifted from, the generated `agentic/v1`
conformance matrix. They have been retired. The page stays so that existing links resolve.

Where the content now lives:

- Capability status per runtime (`supported`, `partial`, `unsupported`, `not_tested`), per fixture
  outcome and per-binding notes: [capabilities.md](../capabilities.md). It is generated by
  `spec/tools/conformance_matrix.py` from a run of the shared fixtures and is the only place a
  runtime is called `supported` for an `agentic/v1` capability.
- What each conformance tested runtime is made of, how it restarts, and where it stands in the
  matrix: the pages under [docs/runtimes/](../runtimes/README.md) (common primitives, Flink,
  Pekko, Clojure, pure Python, Python facade, PyFlink, experimental adapters).
- The engine adapters that are not conformance tested (Faust, Kafka Streams, Temporal, Pulsar,
  Ray, NATS, Quarkus, Spring, Celery, Dask, Airflow, Go): their status, guards and allowed
  consumers in [ports/experimental/README.md](../../ports/experimental/README.md), the per-engine
  design notes in this directory, and the decision guide in
  [choosing-a-backend.md](choosing-a-backend.md).

No table on this page: a second matrix would have to be kept in step by hand, which is what
the generated one exists to avoid.
